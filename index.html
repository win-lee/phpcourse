💻 Die Nummern entsprechen unseren Unterrichtsdateien (01–11)

PHP läuft auf dem Server und erzeugt HTML, das im Browser ankommt. Während HTML nur statisch ist (jeder sieht dasselbe), kann PHP Inhalte dynamisch berechnen. Die Themen hier folgen genau unseren Dateien 01_first.php bis 11_zufallszahlen.php – schau sie dir parallel an!

Dein PHP-Skript beginnt mit <?php – ab hier wird Code ausgeführt. Mit echo gibst du Text aus, und mit Kommentaren dokumentierst du dein Programm für dich und andere.

01_first.php
<?php
// Kommentar (wird vom PHP Programm ignoriert)

/*
Kommentare können
auch mehrzeilig sein
*/

// Ausgabe in PHP
echo "Hello World!";
echo "<br>";
echo "<b>Good</b> Morning...";
?>

🔍 Was du hier lernst

  • echo gibt alles aus, was in den Anführungszeichen steht
  • HTML-Tags funktionieren im String: "<br>" erzeugt einen Zeilenumbruch, "<b>...</b>" fetten Text
  • // für einzeilige Kommentare, /* ... */ für mehrzeilige – der Server ignoriert sie
Merke dir: Jede Anweisung endet mit einem Semikolon (;). Vergisst du es, gibt PHP einen Parse Error – der häufigste Anfängerfehler!
✏️ Deine Aufgabe: Erstelle eine Datei 01_first.php und gib deinen eigenen Namen mit echo aus – einmal normal und einmal fett.

PHP lebt mitten im HTML: Überall, wo dynamischer Inhalt gebraucht wird, öffnest du kurz den PHP-Block, rechnest etwas aus – und der Browser bekommt fertiges HTML.

02_hellohtml.php
<!DOCTYPE html>
<!-- HTML Kommentar -->
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>PHP & HTML</title>
</head>
<body>
    <h1>Willkommen <?php echo "Winnie"; ?></h1>
    <p>Heute ist <?php echo "<i>Donnerstag</i>"; ?> </p>
</body>
</html>

🔍 Was du hier lernst

  • <?php ... ?> kann beliebig oft mitten im HTML geöffnet und geschlossen werden
  • Der Browser sieht nur das Ergebnis – im Quelltext der Seite steht kein PHP mehr
  • Es gibt zwei Kommentar-Arten: <!-- ... --> für HTML, // für PHP
Merke dir: Denk immer serverseitig! Der Server ersetzt die PHP-Blöcke durch ihre Ausgabe – dann erst wird die Seite an den Browser geschickt.
✏️ Deine Aufgabe: Baue eine eigene Seite 02_hellohtml.php mit Überschrift, Absatz und deinem Namen per echo im HTML.

Variablen speichern Werte, die du später wieder verwenden oder verändern kannst. Jede Variable beginnt mit einem $-Zeichen.

03_variablen.php
<?php
// Variablen in PHP mit $ am Anfang
$name = "Gertraud";

$name = "Fritz"; // string (=Text)
$zahl = 9; // integer (=ganze Zahlen)
$komma = 4.5; // float (=Kommazahlen mit PUNKT)

// Ausgabe einer Variable: einfach in echo reinschreiben
echo "Willkommen <b>$name</b>";

// Zweite Möglichkeit: Verknüpfen mit Punkt
echo "<br>Die Variable zahl hat den Wert ".$zahl;
?>

🔍 Was du hier lernst

  • string = Text in Anführungszeichen, integer = ganze Zahl, float = Kommazahl mit Punkt (4.5, nicht 4,5!)
  • Eine Variable kann überschrieben werden: $name ist am Ende "Fritz"
  • Zwei Wege der Ausgabe: direkt einbetten ("Willkommen $name") oder mit Punkt verknüpfen ("Wert: " . $zahl)
Achtung: Kommazahlen schreibt man mit Punkt: $komma = 4.5; – nicht 4,5. Mit Komma erhältst du eine Fehlermeldung!
✏️ Deine Aufgabe: Lege Variablen für deinen Namen, dein Alter und deine Lieblingszahl an und gib einen schönen Begrüßungssatz damit aus.

Möchtest du etwas 10-mal wiederholen? Schreibst du 10 Zeilen? Nein – dafür gibt es die for-Schleife. Sie hat genau drei Parameter:

04_schleife.php
<?php
// FOR Schleife
// Parameter 1: Startwert (Zählvariable)
// Parameter 2: Endwert / Abbruchbedingung
// Parameter 3: Schrittweite / Veränderung
// Starte mit $i bei 1 und addiere 1, so lange $i kleiner 10 ist
for ($i=1; $i<=10; $i++) {
    echo "FOR Schleife $i";
    echo "<br>";
}
?>

🔍 Die drei Parameter im Detail

  • Startwert: $i=1 – die Zählvariable beginnt bei 1
  • Abbruchbedingung: $i<=10 – läuft, solange $i kleiner oder gleich 10 ist
  • Schrittweite: $i++ – erhöht $i nach jedem Durchlauf um 1
Merke dir: $i++ ist die Kurzform von $i = $i + 1. Die Variable $i nennt man Iterator oder Zählvariable.
✏️ Deine Aufgabe: Schreibe eine Schleife, die von 1 bis 20 zählt. Tipp: Nur die Abbruchbedingung ändern!

Jetzt kombinieren wir alles: Die Schleife läuft auf dem Server und erzeugt HTML – daraus wird eine Liste mit 20 Einträgen, ohne dass wir 20 Zeilen schreiben!

05_htmlschleife.php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>HTML Schleife</title>
</head>
<body>
    <ul>
    <?php
    for ($i=1; $i<=20; $i++) {
        echo "<li>xxx $i</li>";
    }
    ?>
    </ul>
</body>
</html>

🔍 Was hier passiert (Schritt für Schritt)

  • Der Browser lädt die Seite → der Server führt den PHP-Block aus
  • Die Schleife läuft 20-mal und erzeugt jedes Mal ein <li>-Element
  • Der Browser erhält am Ende 20 fertige Listeneinträge – xxx 1 bis xxx 20
Merke dir: Das ist das Grundprinzip dynamischer Webseiten: PHP erzeugt HTML – aus Daten, aus Berechnungen, aus Schleifen. Statt 20 Zeilen tippen: 3 Zeilen PHP!
✏️ Deine Aufgabe: Ersetze xxx durch etwas Sinnvolles (z. B. "Schüler:in Nr.") und erstelle zusätzlich eine Tabelle mit <table>, in der die Schleife die Zeilen erzeugt.

Dein Programm soll entscheiden können – je nach Wert einer Variable. Dafür gibt es die Abfrage (auch Verzweigung genannt) mit if, else if und else.

06_abfrage.php
<?php
$zahl = 8;
// Abfrage / Verzweigung / Überprüfung mit if
if ($zahl > 10) {
    echo "größer 10";
}
else if ($zahl > 5) {
    echo "größer als 5 aber kleiner gleich 10";
}
else {
    echo "kleiner als 5";
}
?>

🔍 Was du hier lernst

  • PHP prüft die Bedingungen von oben nach unten – die erste wahre Bedingung gewinnt, der Rest wird übersprungen
  • Mit $zahl = 8: 8 > 10 ist falsch → weiter; 8 > 5 ist wahr → Ausgabe „größer als 5 aber kleiner gleich 10“
  • else ist der Notausgang: es greift, wenn keine Bedingung stimmt
Merke dir: Die Reihenfolge ist entscheidend! Schreibst du erst if ($zahl > 5) und dann else if ($zahl > 10), kann der zweite Fall nie eintreten – denn 11 ist auch größer als 5. Immer von eng nach weit prüfen!
✏️ Deine Aufgabe: Schreibe eine Noten-Abfrage: Bei einer Variable $note soll „Sehr gut“ (1), „Gut“ (2), „Bestanden“ (3–4) oder „Nicht bestanden“ (5–6) ausgegeben werden.

Hier wird es richtig spannend: Die Benutzer:in gibt etwas ein – und dein PHP-Skript reagiert darauf. Das HTML-Formular schickt seine Daten an denselben Server, der sie in der Superglobalen $_POST ablegt.

07_formular.php
<form method="post">
   <input name="eingabe" placeholder="Gib irgendwas ein" required>
   <input name="alter" placeholder="Alter" type="number">
   <button type="submit">Abschicken</button>
</form>

<?php
// 07_formular.php

echo $_POST['eingabe'];
echo "<br>";
$alter = $_POST["alter"];
echo "Dein Alter: $alter";

$gebjahr = 2026-$alter;
echo "<br>Du bist geboren in $gebjahr";
?>

🔍 Was du hier lernst

  • Jedes <input> mit einem name-Attribut landet nach dem Abschicken in $_POST['name']
  • method="post" im Formular legt fest: die Daten reisen unsichtbar im Request
  • Mit der Eingabe kannst du rechnen: $gebjahr = 2026 - $alter; – das kann reines HTML niemals!
  • required im HTML sorgt dafür, dass das Feld nicht leer abgeschickt werden kann
Merke dir: Formular und PHP stehen in derselben Datei – die Seite schickt die Daten an sich selbst. Beim ersten Aufruf ist $_POST noch leer, erst nach dem Klick auf „Abschicken“ sind die Daten da.
Achtung: Beim allerersten Aufruf der Seite gibt es noch keine Formulardaten – PHP zeigt dann Warnungen an. Wie man das sauber löst, lernst du in Lektion 09 mit isset().
✏️ Deine Aufgabe: Erweitere das Formular um ein Feld für „Wohnort“ und gib einen vollständigen Satz damit aus, z. B. „Du heißt ..., bist ... Jahre alt und wohnst in ...“.

Derselbe Ablauf wie in Lektion 07 – nur mit method="get". Der wichtigste Unterschied: Bei GET landen die Eingaben sichtbar in der URL.

08_formular_get.php
<form method="get">
   <input name="eingabe" placeholder="Gib irgendwas ein" required>
   <input name="alter" placeholder="Alter" type="number">
   <button type="submit">Abschicken</button>
</form>

<?php
// 08_formular_get.php

echo $_GET['eingabe'];
echo "<br>";
$alter = $_GET["alter"];
echo "Dein Alter: $alter";

$gebjahr = 2026-$alter;
echo "<br>Du bist geboren in $gebjahr";
?>

Nach dem Abschicken sieht die Adressleiste so aus:

URL nach dem Abschicken
.../08_formular_get.php?eingabe=Hallo&alter=17

📮 GET oder POST – wann was?

  • GET: Daten stehen in der URL – gut für Suchen und Filter, man kann die Seite verlinken und als Lesezeichen speichern. Nicht für Passwörter!
  • POST: Daten reisen unsichtbar im Request – gut für Passwörter und sensible Angaben
Merke dir: In der URL erkennst du GET-Formulare am Fragezeichen: alles dahinter sind Name-Wert-Paare, getrennt durch &. Ruf die URL doch mal direkt mit eigenen Werten auf – ganz ohne Formular!
✏️ Deine Aufgabe: Schreibe eine „Suchseite“ mit GET: ein Feld für einen Suchbegriff, und die Seite gibt aus, wie viele Buchstaben der Begriff hat (strlen()).

Jetzt bauen wir alles zusammen: ein vollständiges HTML-Dokument mit Formular – und eine saubere Prüfung, ob überhaupt etwas gesendet wurde. Dafür sorgt isset().

09_formular-html.php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Formular mit HTML</title>
</head>
<body>
    <h1>E-Mail check</h1>
    <form method="post">
        <input name="email" type="email" placeholder="E-Mail">
        <button type="submit">Überprüfen</button>
    </form>
    <p>
    <?php
        if ( isset($_POST["email"]) ) {
            $email = $_POST["email"];
            echo "Deine E-Mail $email ist gültig";
        }
    ?>
    </p>
</body>
</html>

🔍 Was du hier lernst

  • isset($_POST["email"]) prüft: Wurde das Feld überhaupt abgeschickt? So vermeidest du Warnungen beim ersten Seitenaufruf
  • type="email" lässt den Browser selbst prüfen, ob eine gültige E-Mail-Adresse eingegeben wurde
  • Die Ausgabe steht genau dort im HTML, wo der PHP-Block ist – hier im <p>-Element
Merke dir: Das ist das professionelle Muster für fast jede Formular-Seite: Formular oben, if (isset(...)) darunter – erst prüfen, dann verarbeiten.
✏️ Deine Aufgabe: Baue einen „Login-Check“: Felder für Benutzername und Passwort (POST!). Mit if und isset() prüfst du, ob beide ausgefüllt sind – wenn ja: „Willkommen!“, wenn nein: „Bitte alle Felder ausfüllen.“

Ein echtes Formular hat mehr als ein Textfeld: Radio-Buttons für Auswahlmöglichkeiten, ein Dropdown (<select>) – und nach dem Abschicken bleiben die Eingaben dank PHP-Prefill erhalten.

10_formular-prefill.php
<?php
// 10_formular-prefill.php

if ($_POST) {
    $eingabename = $_POST["eingabename"];
    echo "Dein Name: $eingabename<br>";

    $hobby = $_POST["hobby"];
    echo "Dein Hobby: $hobby";

    $essen = $_POST["essen"];
    echo "<br>Du isst: $essen";
}

?>

<form method="post">
<input name="eingabename" value="<?php echo $eingabename;?>" placeholder="Gib deinen Namen ein">
<br>

<input type="radio" name="hobby" value="Langlaufen">Langlaufen
<input type="radio" name="hobby" value="Padel">Padel

<br>
Essen:
<select name="essen">
    <option value="Pizza">Pizza</option>
    <option value="Nudelsalat">Nudelsalat</option>
    <option value="Sushi">Sushi</option>
</select>

<br><br>
<button>Abschicken</button>
</form>

🔍 Was du hier lernst

  • if ($_POST) ist die Kurzform von „wurde irgendwas per POST geschickt?“ – wie isset() in Lektion 09
  • Prefill: value="<?php echo $eingabename;?>" schreibt die alte Eingabe zurück ins Feld – der Name bleibt nach dem Abschicken stehen
  • Radio-Buttons mit gleichem name bilden eine Gruppe – nur eine Option wählbar
  • Dropdown: <select> mit <option value="..."> – in PHP landet der value in $_POST
Merke dir: Das name-Attribut entscheidet alles: gleiches name = gleiche Gruppe (Radio), und unter genau diesem name findest du den Wert in $_POST.
✏️ Deine Aufgabe: Ergänze eine eigene Radio-Gruppe (z. B. Lieblingsfach) und ein zweites Dropdown – und fülle beide nach dem Abschicken wieder vor.

Mit rand() erzeugt PHP Zufallszahlen – die Basis für Spiele, Zufallsbilder und Überraschungen auf der Webseite.

11_zufallszahlen.php
<?php
// 11_zufallszahlen.php

// Zufallszahlen in PHP mit rand(MIN, MAX)

$zuza1 = rand();
echo "Zufallszahl1: $zuza1<br>";

$zuza2 = rand(1, 100);
echo "Zufallszahl2: $zuza2<br>";

$zuza3 = rand(500, 800);
echo "Zufallszahl3: $zuza3<br>";

?>

🔍 Was du hier lernst

  • rand() ohne Parameter: eine große, beliebige Zufallszahl
  • rand(1, 100): eine Zufallszahl zwischen 1 und 100 (beide Grenzen sind erlaubt)
  • rand(500, 800): du bestimmst selbst den Bereich – z. B. für einen Würfel rand(1, 6)
Merke dir: Bei jedem Seitenaufruf kommt eine neue Zahl – genau so funktioniert das Zahlenratespiel in der Übung unten!
✏️ Deine Aufgabe: Simuliere einen Würfel: Gib bei jedem Aufruf eine zufällige Zahl von 1 bis 6 aus – und baue dazu das passende Emoji 🎲 aus.

Aufgabe (quadratkarten_schritt1): Nimm die angehängte Datei als Grundlage (drei statische Karten als Beispiel) und programmiere in PHP die Wiederholung einer Karte, um die Quadratzahlen jeder Zahl von 1 bis 15 darzustellen. Suche den HTML-Code, der wiederholt werden muss, und verändere ihn so, dass jeweils die richtigen Informationen auf der Karte stehen. Unterscheide danach in der Schleife, ob die Zahl gerade oder ungerade ist: gerade → <div class='card even'>, ungerade → <div class='card odd'>.

Tipp: Gerade/ungerade prüfst du mit Modulo: $i % 2 == 0 heißt „durch 2 teilbar“. Das ist die flexible Variante – statt für jede Zahl eine eigene if-Abfrage zu schreiben (siehe Demo-Karte unten!).
quadratkarten_schritt1.php – Kernidee
<?php
for ($i=1; $i<=15; $i++) {
    $quad = $i*$i;
    if ($i%2 == 0) $klasse = "even";
    else $klasse = "odd";
    echo "<div class='card $klasse'>
        <h2>$i</h2>
        <p>Quadrat:<br>$quad</p>
    </div>";
}
?>

Aufgabe (quadratkarten_schritt2): Ergänze die Datei aus Schritt 1 um ein Formular, mit dem man die Anzahl der Karten bestimmen kann. Die Schleife läuft dann nicht mehr bis 15, sondern bis zur eingegebenen Anzahl.

Aufgabe (zahlenraten.php): Erstelle ein Zahlenratespiel: Der Spieler / die Spielerin hat pro Zahl nur einen Versuch. Nach dem Raten wird ausgegeben, ob es RICHTIG oder FALSCH war – z. Pro Tipp: Eine Zufallszahl zwischen 1 und 100 bekommst du mit rand(1, 100) – siehe Lektion 11. Im Musterbeispiel wird mit 1 bis 5 gespielt.
zahlenraten.php – Kernidee
<?php
if (isset($_POST["tipp"])) {
    $zufallszahl = rand(1, 5);
    $tipp = $_POST["tipp"];
    if ($tipp == $zufallszahl) {
        echo "Meine Zahl war $zufallszahl. Du hast $tipp geraten! Das ist RICHTIG!! :-)";
    }
    else {
        echo "Meine Zahl war $zufallszahl. Du hast $tipp geraten! Das ist FALSCH!! :-(";
    }
}
?>
<form method="post">
    <input name="tipp" type="number" placeholder="Errate mich!">
    <button>Raten!</button>
</form>

Lern-Beispiel aus dem Unterricht (abfrage-schleife.php): 26 Blöcke mit Überschrift und Text – und nach jedem zweiten Block soll ein zusätzliches <hr> ausgegeben werden. Dafür kombinieren wir erstmals Schleife + Abfrage – und lernen dabei den Modulo-Operator kennen.

abfrage-schleife.php – die flexible Variante
for ($i=1; $i<=26; $i++) {
    echo "<b>Überschrift vom Block $i</b>
    <br>
    <em>Ich bin ein Text vom Block</em>
    <hr>";

    // nach jedem zweiten Block ein <hr> zusätzlich ausgeben
    // Lösungsvariante 2 (eher flexibel)
    // Modulo (%-Zeichen) ergibt den Rest einer Division
    if ($i % 2 == 0) {
        echo "<hr>";
    }
}

Im Unterricht haben wir auch die Variante 1 besprochen: für jede gerade Zahl eine eigene if-Abfrage (if ($i==2) ... if ($i==4) ... if ($i==6) ...) – das funktioniert, ist aber „nicht sehr flexibel“: Bei 26 Blöcken bräuchtest du 13 Abfragen, und bei jeder Änderung der Blockzahl müsstest du alle anpassen.

Merke dir: $i % 2 ist der Modulo-Operator – er liefert den Rest der Division. Gerade Zahlen haben Rest 0, ungerade Rest 1. Mit einer einzigen if-Abfrage regelst du alle Fälle – dieselbe Technik wie bei den Quadratkarten und in Lektion 06!
